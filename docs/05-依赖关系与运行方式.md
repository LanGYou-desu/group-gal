# 05 · 依赖关系与运行方式

## 1. 依赖总览

```
┌─────────────────────────── 运行时（玩家侧） ───────────────────────────┐
│  浏览器（唯一依赖）                                                     │
│   ├─ DOM + CSS（含 backdrop-filter、CSS 变量、动画）                     │
│   ├─ Web Audio API        ← 需要，用于合成 BGM / 音效                   │
│   ├─ localStorage         ← 需要，存档 + 阅读偏好；不可用时静默降级       │
│   ├─ File API（可选）      ← 只在你选择"本地音乐"时使用                  │
│   └─ 内联 SVG              ← 立绘剪影，无网络请求                        │
└───────────────────────────────────────────────────────────────────────┘
┌─────────────────────────── 开发时（可选） ─────────────────────────────┐
│  node（v18+）   ← 跑剧本完整性/可达性校验脚本                           │
│  python3        ← 起本地静态服务器（也可换成任意静态服务器）             │
└───────────────────────────────────────────────────────────────────────┘
```

**零第三方依赖**：没有 npm 包、没有构建产物、没有任何 `http(s)://` 资源引用（唯一的外链是"关于页"里的备选曲源署名链接，点击才访问）。

## 2. 三种运行方式

### 方式 A：直接双击（推荐，零环境）

```bash
# 用系统默认浏览器打开
xdg-open group-chat-galgame-v1.html   # Linux
open group-chat-galgame-v1.html       # macOS
start group-chat-galgame-v1.html      # Windows
```

`file://` 协议下所有功能可用（localStorage、Web Audio、SVG 均支持）。移动端可把 HTML 传到手机后用浏览器打开。

### 方式 B：本地静态服务器

```bash
cd /workspace
python3 -m http.server 8931
# 浏览器访问 http://localhost:8931/group-chat-galgame-v1.html
```

适合需要多设备访问、或想用浏览器 DevTools 断点调试的场景。

### 方式 C：放进任意静态托管

整个交付物就是**一个文件**，扔到任何静态托管（GitHub Pages / 对象存储 / 内网 nginx）即可在线玩。

## 3. 键位与交互

| 操作 | 效果 |
|------|------|
| 点击屏幕 / `Space` / `Enter` | 推进：打字中→补完当前句；句末→下一句；节点末→下一节点 |
| `A` | 切换 手动 ⇄ 自动播放 |
| `S` | 切换文字速度 慢→普→快 |
| `Esc` | 关闭群成员抽屉 / 设置弹窗 |
| 顶栏 👥 | 打开群成员羁绊面板（打开时点击屏幕不推进，点空白处收起） |
| 顶栏 📣 | 复读上一条群消息（仅聊天模式；水群值 +1；连刷 3 次触发 BE-24） |
| 顶栏 ▶/🐢 | 自动播放 / 文字速度（等价于 A / S） |
| 顶栏 🔊 / 🎵 / ⌂ | 音效开关 / 音乐设置（BGM 开关、曲目试听、本地音频）/ 回标题 |

## 4. 文件依赖关系

```
group-chat-galgame-v1.html
 ├── 无外部脚本 / 样式 / 图片 / 音频
 ├── 运行时读取：localStorage["xqxq_gal_v1"]（存档）
 │                localStorage["xqxq_gal_pref"]（偏好）
 └── 运行时可选读取：用户选择的本地音频文件（File API，仅内存）
```

三个 HTML 版本**互相独立**，不共享资源，可单独分发。

## 6. 剧本校验脚本

改剧本后建议跑一次静态校验（脚本在 [`tools/validate.js`](../tools/validate.js)，零依赖，只需要 node）：

```bash
node tools/validate.js                       # 默认校验 v2.0 完整版
node tools/validate.js group-chat-galgame-v1.html   # 或指定其它版本
```

该脚本会**自动发现**主线选择点与 hub 支线组（v2 的 hub「一次性支线」也计入），
再用集束搜索验证每个角色都能成为羁绊最高者。

校验内容：

1. **跳转可解析**：所有 `next` / `o[].goto` 要么落在 `NODES`，要么是合法的 `__end_*`（须在 `ENDINGS`）/`__ge_*`（须有 `ge_*` 节点）；
2. **引用完整**：台词说话人、`fx.a` 角色键、立绘 `c`、`PRIORITY`/`GE_SLOTS`/`ROUTE_START` 全部指向存在的 `CH`/节点；
3. **全路线可达性**：穷举共通线全部选择组合（约 630 万条），逐一模拟"羁绊最高者"判定，确认 15 位角色都能成为最高羁绊（含"空気≥3 → 第 81 人 END"的排除）。

## 7. 常见问题（FAQ）

| 问题 | 原因与处理 |
|------|-----------|
| 点开始后没有声音 | 浏览器要求音频在用户手势后启动：先点一下页面任意处；或检查顶栏 🔊/音乐设置 |
| 早期版本玩到第 7 天卡死/报错 | 豆包版 `pickRouteLabel` 缺陷（`CH[路线id]` 为 undefined）。请使用 `group-chat-galgame-v1.html`，已修复，详见 [07](./07-版本对比与v1.0合并说明.md) |
| 刷新后没有进度 | 存档在 localStorage；换文件路径/域名或使用隐私模式会隔离存储。标题页「继续游戏」在无存档时置灰属正常 |
| 想边玩边听真实曲目 | 音乐设置 →「播放本地音乐」选择你拥有版权的 mp3/ogg（仅本机播放，不会上传） |
| 旧存档字段缺失（如 `w`、`fxDone`） | 均做了兜底（`||0`、`||{}`），可直接继续使用 |
