## 5. 内容生产管线

```
① 导出        QQ 客户端导出两批聊天记录 → 按 QQ 号拆分为 52 个 md（members.zip）
② 归档归并     按 QQ 号归并曾用名/现用名；标注 owner/admin/bot；统计发言量与时间段
③ 分析画像     report.pdf：整体画像 → 活跃分层 → 逐人画像 → 关系网络 → 十大问题
④ 角色设计     CH：从画像中提炼"行为特征 → 人设一行 + 主题色 + emoji + 发型"
⑤ 结构设计     七日共通线（每日一个群文化主题）→ 第 7 日分岔 → 15 条角色线 → GE 小剧场
⑥ 剧本撰写     NODES：聊天节点（还原群聊节奏）+ AVG 节点（独白/立绘场景）+ 选择肢 fx
⑦ 数值校准     fx 数值 → PRIORITY 平票表 → validate.js 穷举可达性
⑧ 打包发布     单文件 HTML（内联 CSS/JS/SVG/合成音频）
```

## 6. 改编伦理与红线（项目自我约束）

1. **二次虚构**：游戏角色是群内可见行为的"戏剧化聚合"，关于页与报告均声明"与现实人物无关"。
2. **不搬运原始素材**：不引用 `members.zip` 中的真实头像/图片链接；立绘全部用 SVG 剪影替代（只保留 emoji 与主题色）。
3. **隐私处理**：游戏内不使用 QQ 号；真实昵称改为角色化昵称（"闹七""石蒜"等）。
4. **风险内容戏剧化但不美化**：性暗示、语言暴力等作为"可触发 Bad End 的负面选项"存在，用于呈现问题本身，而非鼓励。
5. **版权**：仅内置自合成 BGM；真实曲目（如 Arcaea 版权曲）通过"本地文件"方式由玩家自持自播，不随游戏分发。
