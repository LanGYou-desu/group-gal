## 3. 一次点击的完整数据流

```
玩家点击屏幕
   │
   ▼
document click（交互层）── 弹窗/抽屉打开？→ 拦截或收起抽屉
   │
   ▼
advance()
   ├─ phase==="type"  → skipType()   补完当前句
   ├─ phase==="wait"  → waitResume() 进入下一句（或从 AUTO 切回手动）
   └─ phase==="done"  → go(cur.next) 进入下一节点
                        │
                        ▼
                go(id) → S.id=id; save(); renderNode(node)
                        │
                        ├─ 节点级 fx 结算（applyFx，仅一次）
                        ├─ 切 chat / avg 模式、换背景/BGM/立绘
                        └─ pumpChat / pumpAvg（逐句）
                              ├─ typewrite() 逐字打印（标点额外停顿）
                              └─ holdLine() 句末等待 → 点击/自动续播
                                    └─ 全部播完 → afterLines()
                                          ├─ 有 o → showChoices()（写选项，点击后 applyFx + go）
                                          ├─ 有 next → 显示「点击继续 ▼」
                                          └─ j==="branch" → 空気检查 → pickRoute() → 写路线选项
```

## 4. 状态机（phase）

播放循环不靠"阻塞"，而靠三相位 + 定时器令牌：

| 相位 | 含义 | 谁离开该相位 |
|------|------|-------------|
| `type` | 打字机运行中 | 打完 → `holdLine()`；点击 → `skipType()` |
| `wait` | 一句打完，等待推进 | 点击 → `curAdvance()`；自动模式 → `waitTimer` 超时 |
| `done` | 节点全部播完 | 点击 → `go(cur.next)`；或等待选项被点击 |

- **定时器令牌 `sess`**：`renderNode()` 每次 `++sess`，所有 `setTimeout` 回调先校验 `token!==sess` 即失效，避免"切节点后旧计时器把剧情推着走"。
- **`busy/typer/waitTimer/waitResume/curAdvance`**：分别表示"正在播","当前打字任务","自动播放计时器","等待期点击回调","推进下一句的函数"，由 `clearWait()` 统一回收。

## 5. 存档与回滚设计

| 键 | 内容 | 写入时机 |
|----|------|---------|
| `xqxq_gal_v2`（v1 为 `xqxq_gal_v1`） | 完整状态 `S`（当前节点 id、羁绊 a、资质 s、flags f、节点级 fx 记账 fxDone、支线一次性标记 hubDone、回收进度 unlocked、回滚点 cp、设置 se/bgm/trk） | `go()` 每次跳转、结算 fx、点选支线、解锁结局、修改设置 |
| `xqxq_gal_pref` | 阅读偏好 `{auto,spd}` | 切换自动/速度时 |

- **回滚点 `cp`**：第一次进入分岔（`pickRoute()`）时把当前 `S` 快照存入 `cp`。任意结局卡上出现「↪ 回到分岔之夜」按钮：`loadCP()` 还原存档，但**回收进度/设置/水群值不回滚**，用于刷多结局。
- **`fxDone`**：按节点 id 记录"节点级 fx 已生效"，防止读档重进同一节点重复加羁绊。
- **`hubDone`（v2 新增）**：记录已体验的 hub 支线，配合选项第 4 位 `once` 实现"每条支线只体验一次"。

## 6. 各版本架构对比（引擎进化路线）

| 维度 | v0.2（`group-chat-galgame.html`） | 豆包版 v1.0 | v1.0 合并版 | **v2.0 完整版** |
|------|-----------------------------------|------------|------------|----------------|
| 剧本结构 | 数组 `S`（185 行），`label`+`jump` 跳转 | 对象 `NODES`（124 节点）有向图 | `NODES` 131 节点 | `NODES` 87 节点（hub 支线体） |
| 播放方式 | `async play()` 线性协程 | `phase` 状态机 + 定时器令牌 | 同左 | 同左 |
| 文本呈现 | 一次写入 | 打字机（标点停顿） | 同左 | 同左 |
| 阅读控制 | "快进"开关 | 手动/自动 × 三档 | 同左 | 同左 |
| 存档 | 无 | localStorage + 回滚点 | 同左（+水群值保留） | 同左（+hubDone） |
| 结局系统 | `BEDATA` 9 + `ENDING` 7 | 18 BE + 15 GE | 23 BE + 15 GE | 23 BE + 15 GE |
| 支线结构 | hub（once 去重） | 线性七日 | 线性七日 | **hub（once 去重）+ 分岔（角色线 +2 段）** |
| 立绘 | 通用剪影 + 角色配件 | 发型变体 | 发型变体 | **通用剪影 + 角色配件（v0.2 思路回归）** |
| 复读彩蛋 | 有 | 无 | 移植 | 移植 |
| 音频 | `BGM` 4 曲目 | `AU` 5 曲目×4 织体 + 本地文件 | 同左 | 同左 |

结论：**引擎能力取豆包版（v1 系列），群氛围系统与世界观取 v0.2，剧本在 v2.0 中全部重写**。详见 [07](./07-版本对比与v1.0合并说明.md)。
