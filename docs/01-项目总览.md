# 01 · 项目总览

## 1. 项目定位

`group-gal` 是一个**把真实群聊改写成文字恋爱冒险（Galgame）**的整活项目：

- **输入**：两批 QQ 群聊记录（`members.zip`，5,325 条消息 / 52 名发言者 / 80 人名册）+ 一份群氛围与成员画像分析报告（`report.pdf`，23 页）。
- **输出**：单文件、离线、零依赖的网页游戏。玩家扮演"第 81 位群友"，在 7 天共通线里通过聊天选择积累羁绊，第 7 天走向 15 条角色线之一，并可在「结局回收室」收集 23 个坏结局。
- **风格**：聊天流（模仿 QQ 群界面）+ AVG 双模式；所有角色立绘为 SVG 剪影，BGM 由 Web Audio 实时合成——**不引用任何外部图片/音频资源**。

项目口号（见根 README）：`group-gal 😂😂😂😂😂😂`。

## 3. 三个 HTML 版本是什么关系

| 版本 | 文件 | 定位 |
|------|------|------|
| **v0.2 Demo** | `group-chat-galgame.html` | 早期整活 Demo：《😂群聊 · 全群攻陷计划》。手法是纯聊天流：好感度（沦陷度）+ 水群值 + 复读彩蛋（刷屏 3 次被禁言）+ 群成员抽屉 + 6 条 hub 支线。结局只写到"路线序章"，9 个 Bad End。 |
| **豆包版 v1.0** | `啥子豆包版本.html` | 重写版：《全员问题儿童！😂群聊攻略录》。换成完整的节点图引擎：聊天/AVG 双模式、打字机、手动/自动×三档速度、localStorage 存档、「结局回收室」、18 BE + 15 条好结局（GE）文本。但存在 3 处缺陷（第 7 日分岔会崩溃、选项加成错位、8 条路线不可达）。 |
| **v1.0 完整版** | `group-chat-galgame-v1.html` | **两版合并 + 缺陷修复**：以豆包版引擎为底座，移植 v0.2 的复读/水群值、群成员羁绊面板、蘑菇汤反派际遇，并补写 5 个新结局（23 BE）。经穷举校验 15 条路线全部可达。 |

## 4. 技术栈与设计约束

| 维度 | 选择 | 原因 |
|------|------|------|
| 形态 | 单个 `.html` 文件（内联 CSS+JS） | 双击即玩、方便转发、便于截图整活 |
| 语言 | 原生 JavaScript（ES2017+），无框架 | 零构建、零依赖 |
| 渲染 | DOM + CSS 动画 + 内联 SVG（`silhouette()` 生成剪影立绘） | 不引用外部图片资源 |
| 音频 | Web Audio API 实时合成（5 首 BGM + 6 种音效），另支持读取本地音频文件 | 免版权、离线可播；本地文件仅本机播放 |
| 持久化 | `localStorage`（存档 + 阅读偏好） | 无后端；`file://` 下同样可用 |
| 分发 | 无需服务器；`file://` 直接打开即可 | 降低游玩门槛 |

## 5. 玩法概述（v1.0 完整版）

```
标题画面
  ├─ ▶ 开始游戏 ────────────────┐
  ├─ ↩ 继续游戏（读档）          │
  ├─ 🕳️ 结局回收室（23 BE / 15 GE 收集进度）
  └─ ♪ 音乐 / 关于               │
                                 ▼
序章 → DAY1 入群 → DAY2 卖弱潮 → DAY3 零分与辈分 → DAY4 深夜故事会
     → DAY5 群名片真相 → DAY6 方块开服日 → DAY6 深夜「蘑菇汤际遇」
     → DAY7 季末群战 · 分岔
        ├─「空気」≥3 → BE：第 81 人 END
        └─ 羁绊最高者 → 15 条角色线 →（选择正确）GOOD END 小剧场
```

核心系统：

- **羁绊（S.a）**：选择肢为角色加减好感；顶栏与「群成员」抽屉可实时查看（无视→眼熟→嘴替→宝宝→沦陷）。
- **资质（S.s）**：真诚 / 嘴臭 / 卖弱 / 空気 / 水群值 五项统计。
- **复读**：复读上一条群消息、水群值 +1；同一句连刷 3 次触发「刷屏禁言」BE-24。
- **存档**：自动存于 `localStorage`（键 `xqxq_gal_v1`），含回滚点（第 7 日进入分岔前自动备份，可在任意结局后「回到分岔之夜」）。

## 6. 素材来源与免责声明

- `members.zip`：QQ 客户端导出的聊天记录（含昵称、群名片、角色、时间戳、消息文本，图片/表情/文件以占位形式保留）。
- `report.pdf`：对上述记录的成员画像与风险分析（嘴臭即亲密、卖弱成瘾、性压抑边界、AI 依赖、小圈子排外等十类问题）。
- 游戏中所有角色**均基于群内可见行为的二次虚构**，与现实人物无关；这也是豆包版关于页与报告本身反复强调的立场。
