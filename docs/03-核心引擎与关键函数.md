# 03 · 核心引擎与关键函数

> 目标文件：[group-chat-galgame-v1.html](../group-chat-galgame-v1.html)。
> 行号引用以该文件为准；豆包版对应函数几乎同名同构。

## 1. 引擎总览

引擎是"**事件驱动的节点播放器**"：`go()` 进入节点 → `renderNode()` 布景 → `pumpChat/pumpAvg()` 逐句播 → `holdLine()` 等点击 → `afterLines()` 收尾（选项/下一节点/分岔）。没有 `await`，全靠相位与定时器协作，因此可以随时跳过、变速、存档。

```
go(id) ─► renderNode ─► pump* ─► typewrite ─► holdLine ─► (点击/自动)
                                  ▲                          │
                                  └──── pump*(下一句) ◄──────┘
                                                        afterLines
                                        ┌──────────────┼───────────────┐
                                     有选项 o      有 next        j=branch
                                  showChoices   等待点击继续    pickRoute 分岔
```

## 3. 关键实现细节

### 3.1 结局协议 `__end_*` / `__ge_*`

剧本里跳转目标可以写两种"协议字符串"，`go()` 拦截并转交 `showEnd()`：

| 写法 | 含义 | 例 |
|------|------|----|
| `"__end_nq2"` | 坏结局，查 `ENDINGS.nq2` | 解散式 END |
| `"__ge_naoqi"` | 好结局，查 `NODES.ge_naoqi` 的标题与末句旁白 | 闹七线 GOOD END |

> 分岔节点 `d7b` 由 `j:"branch"` 驱动：`afterLines()` 先检查「空気」资质（`S.s.q>=3` → 直接 `showEnd("pass")` 第 81 人 END），否则 `pickRoute()` 选出羁绊最高者，写成唯一一个"追谁"的选项。

### 3.2 打字机与速度档

```js
const SPEEDS=[
  {n:"慢", type:42, punc:120, autoWait:len=>950+len*62},   // 默认
  {n:"普", type:26, punc:72,  autoWait:len=>680+len*40},
  {n:"快", type:13, punc:34,  autoWait:len=>460+len*24}
];
// typewrite 内部：标点字符（，。！？、…—：）额外停 punc 毫秒
el._timer=setTimeout(step,/[，。！？、…—：]/.test(text[typer.i-1])?sp.punc:sp.type);
```

- 手动模式下，句末显示「点击继续 ▼」；自动模式显示「AUTO 自动播放中…」，等待时长与句长成正比。
- 自动播放中点击：切回手动（`setAuto(false)`），同时把"续播"动作挂到 `waitResume`，不会丢句。

### 3.3 分支判定

```js
const PRIORITY=["naoqi","fish","g","suan","tttt","dan","gen","aka","mian","n305","butter","obra","lusi","liuli","ban"];
const ROUTE_START={naoqi:"r_nq1",fish:"r_f1", ... ,ban:"r_ban1"};

function pickRoute(){
  if(!S.cp){ S.cp=JSON.stringify(S); save(); }   // 进分岔前存回滚点
  let best=null,bv=-999;
  PRIORITY.forEach(k=>{
    if(k==="butter" && !S.f.butterUnlocked) return;  // 黄油猫需 DAY5 解锁
    const v=S.a[k]||0;
    if(v>bv){ bv=v; best=k; }
  });
  S.lastRoute=best; save();
  return best;                                   // 返回角色 key（修复版）
}
```

- **平票规则**：按 `PRIORITY` 表顺序，靠前者胜。
- **可达性**：完整版穷举 629 万条选择路径验证——15 位角色都能成为最高羁绊（原豆包版仅 7 位可达，见 [07](./07-版本对比与v1.0合并说明.md)）。
- `pickRoute()` **返回角色 key**；路线入口由 `ROUTE_START[k]` 映射。豆包版此处返回路线 id 再交给 `CH[...]` 取色，导致 `undefined.e` 崩溃——完整版已修复。

## 4. 状态与存档

```js
function freshState(){
  return {id:"start", a:{}, s:{z:0,r:0,m:0,q:0,w:0}, f:{}, fxDone:{},
          unlocked:[], cp:null, se:true, bgm:true, trk:"title"};
}
```

| 字段 | 含义 |
|------|------|
| `id` | 当前节点 id（"继续游戏"从这里恢复） |
| `a` | 羁绊表 `{角色key: 数值}`（float 无上限；顶栏/抽屉实时展示） |
| `s` | 资质表：`z` 真诚 / `r` 嘴臭 / `m` 卖弱 / `q` 空気 / `w` 水群值 |
| `f` | 剧情 flags（`butterUnlocked` 等） |
| `fxDone` | 已结算过节点级 fx 的节点 id 集合 |
| `unlocked` | 结局回收记录（`"nq1"`/`"ge_naoqi"`…） |
| `cp` | 第 7 日分岔前的状态快照（JSON 字符串） |
| `se/bgm/trk` | 音效开关 / BGM 开关 / 当前曲目 |

`applyFx(fx)` 是唯一的数值入口：`{a:{角色:+n}}` 加羁绊（负值也允许）、`{s:{z/r/m/q:+n}}` 加资质（自动闪烁）、`{f:"flag"}` 置位。

## 5. 音频引擎 `AU`

- **结构**：`master ─► destination`；`musicGain`、`seGain` 分总线，便于独立开关。

| 曲目 `trk` | bpm | 织体 `type` | 使用场景 |
|-----------|-----|------------|---------|
| `title` | 72 | pad | 标题画面 |
| `daily` | 112 | pluck | 日常（DAY1-3、5） |
| `night` | 66 | bell | 深夜故事会、凌晨剧情 |
| `tense` | 126 | pulse | 群战、蘑菇汤际遇 |
| `end` | 56 | pad | 所有结局卡 |

- **调度**：`tick()` 用 25ms 心跳 + 前瞻 0.12s 的 lookahead 调度（`nextT`），按 16 分音符推进；每小节首拍铺和弦 pad + 低音，按 `type` 选择 pluck/bell/pulse/pad 的节奏型。
- **音效** `sfx(type)`：`click`（点击）、`pop`（消息出场）、`chime`（选项/GE）、`bad`(未用)、`withdraw`（撤回/坏结局，频率 440→110Hz 下滑）。
- **本地音频**：`m-file` → `<input type=file accept="audio/*">` → `AU.playFile(file)` 用 `URL.createObjectURL` 循环播放；`usingFile=true` 时暂停合成 BGM（版权提示见关于页）。
- **浏览器限制**：AudioContext 需用户手势后启动——点击/`pointerdown` 时 `AU.init()`，并处理 `suspended → resume()`。

## 6. 防御性设计速记

1. **定时器令牌 `sess`**：切节点即令旧计时器作废。
2. **`clearWait()`**：统一清理 `waitTimer/waitResume/curAdvance` 与提示条。
3. **`fxDone`**：节点级数值只结算一次。
4. **`go()` 兜底**：目标节点不存在时 `console.error` 并停下（不会静默串线）。
5. **回滚点保留项**：`unlocked/se/bgm/s.w` 在 `loadCP()` 中人工保留，避免刷结局时丢收集进度。
