# 性格与价值观：面包

> 材料：群聊记录（2026-10-08 ~ 10-10，本人发言 152 条）。
> 篇幅限制：以下均为**可观测行为**，不使用人格诊断标签；材料中的口臭 / 性向类内容仅作行为描述，不复述针对他人的原句。

## 核心价值观

- **玩谱要有规矩**——为「一起玩」设置门槛（`verbatim`：「我只跟这种人玩：不允许新手越级骂铺面，骂游戏制作人的同时不允许骂游戏制作参与者的，规矩性强，可以找我领一个嘴巴子」，10-09）
- **直球锐评谱面**——对好坏直接下判，不留情面（`verbatim`：「各个难度都有死妈谱」「ae真比7.0那几个死妈」「反正比红ae简单就对了」）
- **围观吃瓜但不投入**——观察他人的 cp 文化（`verbatim`：「我发现那些群里的人很喜欢磕cp」「自动给arc的每个人填充了完整的女同世界观」「我真有点磕他们仨了」）
- **自封江湖名号**——给自己的玩法起名并当身份用（`verbatim`：「我是拍框大王」）
- **管理员在场**——以群管理员身份发全群公告（`verbatim`：「@全体成员」）

### 矛盾面（材料内自证）

- 一边以管理员身份立「规矩」，一边高频使用口臭表达（`verbatim`：「你妈的」；`artifact`，同一时段两类表达并存；具体指向不在此复述）

## 口头禅与表达习惯

- 高频短句：「什么东西」（同批 2 次）、「who」「谁」「这几把啥」（`verbatim`）
- 「可惜」式收尾：一句总结错过（`verbatim`：「可惜」「可惜丛雨没给我钱」）
- 自封名号反复使用（`verbatim`：「我是拍框大王」）
- 「没绷住」式反应（`verbatim`：「这下我真没绷住」「好笑吗」）

## 情绪模式

### 积极情绪
- 触发场景：拆谱成功 / 吃到瓜 / 赢下挑战
- 表现：短促兴奋（`verbatim`：「串的有点爽」「这下我真没绷住」「赢了」）

### 消极情绪
- 触发场景：遇到「死妈谱 / 水谱」
- 表现：直接点名谱面差（`verbatim`：「各个难度都有死妈谱」「非常水」「风暴确实有点水」）
- 触发场景：看不懂群内话题
- 表现：连续疑问（`verbatim`：「我怎么没看懂」「这是人类吗」）

### 压力反应
- 上头时连发脏话式感叹（`verbatim`：「哎呦我操」「我操」「牛逼坏了」）

## 社交偏好

- 角色：**管理员 + 锐评者**；@ 与回复集中在黄油猫、Tttt、群主（`artifact`，各 3-4 次）
- 用 @全体发布内容、组织话题（`verbatim`：「@全体成员」）
- 维护关系靠「同场玩 / 互相锐评」，而非问候（`artifact`）

## 兴趣与审美

- **音游与拆谱**：分析谱面手法（`verbatim`：「判定够宽直接拍」「手飞不过去身体补偿」「我突然想起来我封焰打过18粉」）
- **建模**：以建模自嘲（`verbatim`：「我知道我的建模成了冲刺绳蛆」）
- **吃瓜 / 观察**：围观群内 cp 生态（`verbatim`：「我发现那些群里的人很喜欢磕cp」「自动给arc的每个人填充了完整的女同世界观」）

## 自我认知 vs 他人印象

- TA 说自己：自封强势名号、自嘲建模（`verbatim`：「我是拍框大王」「我知道我的建模成了冲刺绳蛆」）
- 他人评价：Tttt 说「面包是我的」「面包打舞萌一蹦一跳的」「鬼歌王比面包美味程度还是差一点」，Obra Dinn 说「这面包好高冷」（`verbatim` 他人提及，10-08 ~ 10-10）
