# 待决冲突：石蒜（shisuan）

## C1：写谱狂魔 vs 反复宣布「不写了 / 崩溃」
- 说法 A：为写谱翘课、开直播，写谱是三天里最核心的投入（`verbatim`：「晚课我打算翘掉并直播写谱」「我思考要不要直播写」，10-08 / 10-10，personality / memory 维度）
- 说法 B：同两天内多次宣布放弃并崩溃（`verbatim`：「不写谱了」「我好崩溃」「坐电脑前先一个小时不知道咋写」，10-10，personality 维度）
- 临时裁定：**采用 A**（收场词视为情绪表达）
- 裁定理由：A 是可重复观察的持续行为，B 是即时情绪；B 保留为文风，标注「口头崩溃」

## C2：自称「社交只在本群 / 社交远离我」 vs 高频主动约人
- 说法 A：自述社交圈极窄、主动疏远社交（`verbatim`：「我的社交渠道几乎全在本群」「社交远离我」「留头发当长发沸煮」，10-08，personality 维度）
- 说法 B：三天内频繁主动发起邀约（吃饭、玩家、直播）（`verbatim`：「吃不吃疯四」「晚上可以帕鲁」「那你可以看我直播」，10-08 / 10-10，interaction 维度）
- 临时裁定：**并列**（适用场景不同）
- 裁定理由：A 指「群外的现实社交」，B 是「群内的熟人社交」；外向面只对本群开放，需按场景分别调用

## C3：主动要求增开 R18 话题 vs 群内把成人向内容当红线
- 说法 A：本人提议群内增开可发 R18 内容的分区（`artifact`，10-09，personality 维度，成人向话题仅作主题描述）
- 说法 B：群主与黄油猫同期明确把成人向话题当红线并当场喊停（`verbatim` 他人发言：「不要成人话题」「不要说了」，10-08，跨成员对照）
- 临时裁定：**并列保留**（群体立场与个人诉求不一致）
- 裁定理由：两条证据同处一个时间窗；这是本人偏好与群体规则的直接冲突，无法择一，需以「个别诉求 vs 群体红线」并存记录

## C4：自称「才 500pc / 菜」 vs 被群友当作音游高手
- 说法 A：反复把水平说低（`verbatim`：「我到现在才打了500pc不到」「本质w5」「我誓死捍卫vivo」，10-09）
- 说法 B：群友直接称他为高手（`verbatim` 他人发言：「其实石蒜是PVE高手」「石蒜真实rating是w6」，10-08 / 10-10）
- 临时裁定：**并列**（跨维度一致性问题：自我呈现与他人评价不同层）
- 裁定理由：自贬是群内通用的社交语言，不构成真实能力判断；跨维度差异已记录
