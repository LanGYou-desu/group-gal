# 待决冲突：黄油猫（cat）

## C1：自称「要戒音游 / 望到头」 vs 音游发言密度最高
- 说法 A：反复表达对音游能力的绝望与退意（`verbatim`：「我是真一眼望到头了」「我要戒掉音游」，10-10，personality / interaction 维度）
- 说法 B：三天内音游话题命中 33 条，持续报分、推分、研究打法（`artifact`：音游/舞萌/成绩主题计数，10-08 ~ 10-10，interaction 维度）
- 临时裁定：**并列保留**
- 裁定理由：A 是即时的情绪化口嗨，B 是可重复观察的持续行为；两者同处一个时间窗，无法判断先后，故并列

## C2：喊停成人向话题 vs 高频参与性别/性向类玩笑
- 说法 A：明确划红线并当场制止（`verbatim`：「不要成人话题」「不要说了」「我要小孩话题」，10-08，personality 维度）
- 说法 B：同期大量使用性别/性向类玩梗表达（`artifact`：性别/性向梗主题命中 8 条，10-08 ~ 10-10，personality 维度）
- 临时裁定：**并列保留**
- 裁定理由：两条证据同窗同场景；可判断的是「粗俗内容拒、擦边玩笑容」这一尺度分层，而非择一

## C3：一次性长文创作 vs 平时 11.8 字短句流
- 说法 A：日常以 11.8 字均长的短句为主（`artifact`：语料统计，interaction 维度）
- 说法 B：能一次写出约 490 字的「爆料体」段子（`artifact`：「的世界将增加新的维度——铜界…」，10-10，memory 维度）
- 临时裁定：**并列**（跨维度差异，非矛盾）
- 裁定理由：短句是日常互动节奏，长文是专门的整活表演，属两种不同的表达模式，需按场景分别调用

## C4：说「退勤 / 退群 / 算了」 vs 从未真正离开
- 说法 A：情绪上来就喊退出（`verbatim`：「退勤」「退群」「我要戒掉音游」，10-08 / 10-10，interaction 维度）
- 说法 B：喊完之后继续长时间高频发言（`artifact`：逐日分布 370/287/216 条，话题延续，interaction 维度）
- 临时裁定：**采用 B**（收场词视为习惯性表达）
- 裁定理由：B 在时间上更晚且可重复观察；A 保留为文风，标注「习惯性表达」
