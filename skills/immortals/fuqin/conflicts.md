# 待决冲突：根哥（fuqin）

## C1：倡导「正常评价 / 不能只看结果」 vs 自身高频贬评
- 说法 A：反复强调评价要有标准、不拿单点成绩下结论（`verbatim`：「正常评价就行了」「不能只看结果」「就拿一个分说是吧」，10-08 / 10-10，personality 维度）
- 说法 B：同期自己也高频用极简贬评给谱面/他人下结论（`verbatim`：「写的一坨屎」「区」，10-08 / 10-09，interaction 维度）
- 临时裁定：**并列保留**
- 裁定理由：两条证据同窗同场景；可判断的是「对外讲标准、对内随手下评」的双标模式，而非择一

## C2：管理员护人 vs 自身高频攻击性用词
- 说法 A：以管理员身份出面护人、喝止围攻（`verbatim`：「别骂石蒜」，10-08，interaction 维度）
- 说法 B：三天内嘴臭/攻击类发言命中 6 条，用词直接（`artifact`：主题计数，10-08 ~ 10-10，personality 维度）
- 临时裁定：**并列保留**
- 裁定理由：护的是「自己人」、攻击多指向「外人/泛对象」；两者并不互斥，反映的是边界内外的差别对待

## C3：反复喊「屏蔽群主 / 不想上课」 vs 三天全程在场并管理
- 说法 A：多次表达退避意愿（`verbatim`：「屏蔽群主一个小时」「我后悔来上课了」「我好想死」，10-08 / 10-10，interaction 维度）
- 说法 B：逐日 290/89/155 条持续发言，并执行管理员清场（`artifact`：逐日分布 + `verbatim`：「删掉色图好了」，10-10，memory 维度）
- 临时裁定：**采用 B**（退避词视为习惯性表达）
- 裁定理由：B 在时间上更晚且可重复观察；A 保留为文风，标注「口头抗议」

## C4：自称「区 / 菜 / 胖」 vs 被群内当作写谱与音游核心
